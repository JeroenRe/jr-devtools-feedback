# JR DevTools feedback

Public bug reports and feature requests for the JR DevTools extensions for Azure DevOps:

- [Merge Conflict Resolver](https://marketplace.visualstudio.com/items?itemName=jr-devtools.ado-merge-conflict-resolver)
- [Bulk Editor](https://marketplace.visualstudio.com/items?itemName=jr-devtools.bulk-editor)

This repository contains no source code; it only tracks issues.

- **Report a bug or request a feature:** [open an issue](../../issues/new/choose).
- **Upvote an existing request:** add a 👍 reaction to the issue.
- **License, billing, refunds or anything private:** email [support@jr-devtools.com](mailto:support@jr-devtools.com).
- **Security issues:** don't open a public issue; see [jr-devtools.com/security](https://jr-devtools.com/security/).

Issues are public. Never post organization names, project or repository names, source code, work item content,
license keys or personal access tokens.

Support policy: [jr-devtools.com/support](https://jr-devtools.com/support/)
